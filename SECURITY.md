# Security policy

Precision is an early-stage browser extension. Please do not report an unpatched security issue in a public issue.

Send a private report to the repository maintainer through GitHub's **Report a vulnerability** flow on the Security tab. Include the affected version or commit, browser and operating system, reproduction steps, and the impact you observed. Avoid including real page content or personal data unless it is necessary to demonstrate the issue.

There is no guaranteed response time while the project is maintained by one person. Please allow time for investigation before publicly disclosing a report.
